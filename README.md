# My First App

Welcome to **My First App**! This is my very first Android application, and I am excited to share it with you. This app is designed to be simple yet functional, providing a welcoming "Hello World" message, followed by a cheerful "Good Morning" greeting. It also includes an interactive button that, when clicked, confirms its functionality with a message that says "Button is working."

Explore the app, enjoy its simplicity, and stay tuned for more exciting features in the future. Feel free to check out the source code on my GitHub repository, and don't hesitate to contribute or provide feedback.
